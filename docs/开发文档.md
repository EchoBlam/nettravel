# 设计
初步原理图
![原理图1](./docs/images/1.png)
用gin+vue写一个提供内网服务的网站，提供两种服务方式：
1. 网站提供内网穿透服务，用户下载一个客户端，下载配置文件(一些配置信息)

2. 给用户提供服务端程序和客户端程序(服务端程序只支持tcp和udp)
